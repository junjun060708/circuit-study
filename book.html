第1讲　参考方向与功率

建议45–60分钟。基础：会做基本乘除，认识电压、电流的单位。

本讲概览

  • 区分参考方向与真实方向
  • 根据电压、电流参考关系判断吸收或发出功率
  • 算完能检查单位和功率平衡

带着问题学

  1. 电流算出负数，是不是电路出了问题？
  2. 同一个电源能不能有时供电、有时吸收能量？
  3. 为什么同样的 u、i，有时功率用 ui，有时用 −ui？

1. 先约定，再计算

电流是电荷流动的快慢，单位是安培 A；电压是两点之间的电位差，单位是伏特 V。分析前先画电流箭头，标电压的正负端。这些标记是我们选择的参考方向，不会强迫实际电流按它流。

规定电流向右为正，算得 i=−2 A，表示真实电流向左、大小为 2 A。不要去掉负号后继续代入原方程；如果改箭头，就要同时改变这个变量的符号。

Uab = Va − Vb；Uba = −Uab

规定电流向下为正，结果为 −0.5 A。实际方向是？

  1. 向上，大小0.5 A
  2. 向下，大小0.5 A
  3. 没有电流
参考答案与提示

答案：向上，大小0.5 A

负号只说明实际方向与参考方向相反。

提示：先保留原参考箭头，再解释负号。

2. 功率要连着参考关系一起看

功率描述能量交换的快慢，单位 W。在吸收功率的约定中，电流参考箭头进入电压标“+”的一端，称关联参考方向，此时 p=ui。若电流箭头从“+”端流出，吸收功率就写 p=−ui。

判断顺序固定为：看箭头与正端的关系 → 选表达式 → 代入带符号的数值。算得吸收功率 p>0，元件吸收能量；p<0，元件向外供能。电源充电、放电时可能呈现不同的能量方向。

关联：p吸收 = ui　　非关联：p吸收 = −ui

某元件 u=6 V，i=2 A，电流从电压正端流出。吸收功率是多少？

我的列式与结果：________________________________________________

参考答案与提示

答案：-12 W

电流从正端流出，用 p吸收=−ui=−6×2=−12 W，表示发出12 W。

提示：先判断是否进入正端。

提示：这里 p吸收=−ui。

3. 电阻：算式可以交叉检查

理想电阻把电能转成热。关联参考方向下 u=Ri，所以 p=ui=i²R=u²/R。R>0 时消耗功率非负。这里的平方式适用于电阻，不是任意元件都能用 u²/R。

例如 4 Ω 电阻通过 2 A 电流，压降为 8 V，耗散 16 W。若只改变参考箭头，变量的符号会相应变化，真实发热不会改变。

pR = i²R = u²/R ≥ 0

4 Ω电阻通过2 A电流，消耗功率是多少？

我的列式与结果：________________________________________________

参考答案与提示

答案：16 W

p=i²R=2²×4=16 W。

提示：电流要平方。

4. 用单位和能量守恒收尾

Ω×A=V，V×A=W。写出单位能发现把电流写成电压、把 u/R 写成 R/u 这类错误。在理想集中参数电路模型中，所有元件按吸收为正计算，瞬时功率的代数和为零。

功率平衡不代表每个元件都吸收相同功率，而是某些元件送出的总功率，等于其他元件当时吸收的总功率。电容、电感的吸收可能表现为储能。

把电路中所有元件按吸收功率为正相加，理想模型的结果应为？

  1. 0 W
  2. 总电源电压
  3. 每个电阻功率都相等
参考答案与提示

答案：0 W

电路满足能量守恒，发出的功率与吸收的功率平衡。

第2讲　元件模型与 KCL / KVL

建议50–70分钟。基础：参考方向、欧姆定律和功率的基本意义。

本讲概览

  • 按节点写电流守恒

带着问题学

  1. 节点处的电流会不会凭空消失？

1. 三个基本模型分别约束什么

电阻的关联电压电流满足 u=Ri。理想电压源固定两端电压，电流由外部电路决定；理想电流源固定支路电流，两端电压由外部电路决定。理想模型没有真实器件的功率、耐压等限制，实际选型还要查资料。

电阻：u=Ri；电压源：u=Us；电流源：i=Is

短路要求两端电压为零，开路要求支路电流为零。短路电流不必为零，开路电压也不必为零。

  2. 支路电流
  3. 输出功率
参考答案与提示

答案：两端电压

电压源约束电压；负载改变时电流、功率可以改变。

2. 节点处写 KCL

理想导线直接相连的点属于同一节点，即使导线拐弯很长，也不能多算节点。基尔霍夫电流定律KCL来自电荷守恒：流入节点的电流总和等于流出总和。

例如流入为3 A，流出有1 A和未知i，则3=1+i，得到i=2 A。也可以全部按流出为正写−3+1+i=0；两种记法一致就行。

∑i流入 = ∑i流出

节点流入3 A，已知一支路流出1 A，另一支路流出多少？

我的列式与结果：________________________________________________

参考答案与提示

答案：2 A

3=1+i，所以i=2 A。

提示：先把流入、流出分别写在等号两侧。

3. 回路中写 KVL

基尔霍夫电压定律KVL用于集中参数电路的电压约束。选定绕行方向，按电位升降写式。采用“电位升高为正”的记法时，经过电源从−到+写+U，经过电阻从+到−写−u。

例如12 V源驱动2 Ω和4 Ω串联，12−2i−4i=0。你也可以把全部项乘−1；不要把某一种符号记法当作唯一合法记法，关键是前后一致。

沿闭合回路：∑电位变化 = 0

4. 受控源要同时看输出与控制量

受控源的数值由电路中另一个电压或电流决定。先看输出是电压源还是电流源，再看等式右边由什么控制：uₒ=μuₓ是电压控制电压源；iₒ=guₓ是电压控制电流源；uₒ=riₓ是电流控制电压源；iₒ=βiₓ是电流控制电流源。

控制关系属于模型的一部分，分析和等效时不能随便删除。器件被叫作“放大器”不能代替对控制关系的判断。

iₒ=g·uₓ 的受控源属于？

参考答案与提示

答案：电压控制电流源

输出是电流，控制量是电压，因此是VCCS。

第3讲　电阻与电源等效变换

建议45–65分钟。基础：串并联、KCL/KVL及源模型。

本讲概览

  • 按连接节点判断串并联

  • 正确变换电压源与电流源

带着问题学

  1. 外部负载一样时，什么样的两个网络才叫等效？
  2. 两个电阻画在一上一下，就一定是并联吗？
  3. 电源变换后，电流源箭头应该朝哪里？

1. 等效是从端口看进去

端口是网络与外部连接的两个端点。端口等效要求：外接相同负载时，两网络的端口电压和电流关系一致。内部元件的电流、功率不必一一相同。

因此，可以用简化网络计算负载，却不能用简化后某个“内部电阻”的功率冒充原网络里某个器件的损耗。这也是以后戴维南等效的基本想法。

  3. 内部支路数量

答案：相同负载下的端口电压、电流

端口等效保留外部电压电流关系，内部不必相同。

2. 串并联由节点关系决定

串联支路通过相同电流，连接处没有其他分流路径，总电阻R=R₁+R₂。并联电阻连接在同一对节点之间，端电压相同，总电导相加。

1/R并 = 1/R₁ + 1/R₂；两只时 R并 = R₁R₂/(R₁+R₂)

例如3 Ω与6 Ω并联为2 Ω，小于任一支路电阻。把R₁+R₂用于并联，或者仅凭图形远近判断连接，都会出错。

3. 分压与分流的使用条件

串联两电阻可按电阻比例分压：U₁=U·R₁/(R₁+R₂)。并联两电阻可按电导比例分流：i₁=I·R₂/(R₁+R₂)。小电阻支路分到较大电流。

U端 = Uₛ − i负载R；Iₛ = Uₛ/R

例如12 V串3 Ω，转换为4 A并3 Ω。只变理想源而不处理它的串/并电阻，不是这个变换。受控源也不能盲目删除控制变量，需保持或正确重新表达控制关系和端口关系。

1. 瞬时功率有平均值，也有来回交换

瞬时功率p(t)=u(t)i(t)。正弦稳态下，其一个周期的平均值是有功功率P=UIcosφ，U、I用有效值，φ=φu−φi。有功反映平均净能量转移，例如电阻发热。

电感和电容会在某些时段吸收能量、另一些时段返回能量，所以瞬时功率可能变号。理想纯电抗平均有功为零，但电流不一定为零，输电导线仍可能因该电流发热。

2. 用P、Q、S描述不同侧面

无功功率Q=UIsinφ，单位var；感性电流滞后时Q>0，容性电流超前时Q<0。视在功率S=UI，单位VA。正弦单相中S²=P²+Q²。
